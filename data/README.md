# Data

## Full dataset (required for real results)

The project uses the Kaggle **Credit Card Fraud Detection** dataset
(ULB Machine Learning Group): 284,807 transactions, 492 frauds (~0.17 %).
Columns: `Time`, `V1`–`V28` (PCA components), `Amount`, `Class`.

The file is ~150 MB and is **not** included in this repository.

Option A – browser: download from
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud, unzip, and place
`creditcard.csv` in this folder (`data/creditcard.csv`).

Option B – Kaggle CLI (needs a Kaggle account + API token in `~/.kaggle/kaggle.json`):

```bash
pip install kaggle
kaggle datasets download -d mlg-ulb/creditcardfraud -p data --unzip
```

The dataset is released under the Database Contents License (DbCL) v1.0;
please read the Kaggle page for terms and citation.

## Bundled sample (synthetic – smoke tests only)

`sample_transactions.csv` is **synthetic** data with the same schema
(2,500 rows, 50 "fraud"). It is generated by `scripts/make_sample_data.py`
and contains **no real transactions**. Use it to check that the pipeline and
the Streamlit app run; do **not** draw conclusions about fraud detection
quality from it.
